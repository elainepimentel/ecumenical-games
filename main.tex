\section{Introduction}
\begin{itemize}
\item Describe Dialogical games for classical and intuitionistic logics
\item How can we combine tactics so that the classical and intuitionistic do not collapse?
\end{itemize}

Outline:
\begin{enumerate}
\item Satisfiability and validity games.
\begin{itemize}
\item Start with an ecumenical game on satisfiability where the players $\I$ and $\Y$ can take the roles of $\T, \Sc,\Si$ for ``tester'' and the ``scheduler'', where the later can assume classical or intuitionistic roles respectively. 
\item Define the satisfiability game on Kripke structures. This will generate a labeled game.
\item Move to a (labelled) validity game.
\item Extract a (labelled) sequent system. 
\item Prove that this system is equivalent to the one with stoup.
\end{itemize}
\item Classical cost of proofs:
\begin{itemize}
\item Start with the sequent system with stoup. 
\item Define a game where the {\em state} is only one sequent. With rules with only one premise, the conclusion is substituted by this premise. When the rule has two premises, $\Y$ chooses one and the game follows from there.
\item Prove adequacy.
\item Define and add classical budget to the games. Each time a classical rule is used, ``pay'' 1. The budget should be a string, and ``paying'' means appending 1 or 0 to the string, depending if the move is classical or intuitionistic. 
\item Define a labelled sequent system, with costs as labels. Difficult question: how to combine them?
\item Try to prove cut-elimination, etc.
\end{itemize}
\end{enumerate}
